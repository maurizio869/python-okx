# 🔊 Python Sound Scripts for Android

Набор скриптов для воспроизведения звуков на Android устройствах через IDE типа Pydroid.

## 📱 Файлы

### Основные скрипты:

1. **`quick_start.py`** - Быстрый тест звука (минимальные зависимости)
2. **`android_sound_player.py`** - Полнофункциональный звуковой плеер
3. **`advanced_sound_generator.py`** - Продвинутый генератор звуков
4. **`audio_file_player.py`** - Работа с аудиофайлами

### Дополнительные файлы:

- **`requirements.txt`** - Список зависимостей
- **`README.md`** - Этот файл с инструкциями

## 🚀 Быстрый старт

### 1. Установка зависимостей в Pydroid:

```bash
# Минимальные зависимости (для quick_start.py)
pip install pygame numpy

# Полный набор (для всех скриптов)
pip install pygame numpy sounddevice pydub scipy
```

### 2. Запуск простого теста:

```python
python quick_start.py
```

## 📋 Описание скриптов

### 🎵 quick_start.py
**Назначение:** Быстрый тест работоспособности звука  
**Зависимости:** pygame, numpy  
**Возможности:**
- Простые тональные сигналы
- Тест разных частот
- Последовательность сигналов
- Простая мелодия

### 🎼 android_sound_player.py
**Назначение:** Полнофункциональный звуковой плеер  
**Зависимости:** pygame, numpy  
**Возможности:**
- Генерация различных типов волн (sine, square, sawtooth, triangle)
- Воспроизведение мелодий
- Последовательности сигналов
- Сигналы тревоги
- Интерактивное меню

### 🌊 advanced_sound_generator.py
**Назначение:** Продвинутая генерация звуков  
**Зависимости:** sounddevice, numpy, scipy  
**Возможности:**
- Аккорды (несколько частот одновременно)
- Скользящие тоны (frequency sweep)
- DTMF тоны (тональный набор)
- Эффекты (fade-in, fade-out)
- Белый шум
- Набор телефонных номеров

### 📁 audio_file_player.py
**Назначение:** Работа с аудиофайлами  
**Зависимости:** pydub, pygame  
**Возможности:**
- Загрузка и воспроизведение аудиофайлов
- Создание и сохранение мелодий
- Применение эффектов
- Создание звуков уведомлений
- Работа с различными форматами

## 🛠️ Установка и настройка

### В Pydroid 3:

1. **Откройте Pydroid 3**
2. **Установите зависимости:**
   - Меню → Terminal
   - `pip install pygame numpy`
   - Для дополнительных возможностей: `pip install sounddevice pydub`

3. **Скопируйте нужный скрипт**
4. **Запустите скрипт**

### Возможные проблемы и решения:

#### ❌ "No audio device found"
- Проверьте разрешения приложения на доступ к микрофону/динамику
- Перезапустите Pydroid
- Попробуйте другой скрипт (quick_start.py обычно работает лучше всего)

#### ❌ "Module not found"
- Убедитесь, что установили все зависимости
- Используйте `pip list` для проверки установленных пакетов

#### ❌ "Permission denied"
- Дайте разрешения приложению в настройках Android
- Попробуйте перезагрузить устройство

## 🎯 Примеры использования

### Простой сигнал:
```python
from android_sound_player import AndroidSoundPlayer

player = AndroidSoundPlayer()
player.play_tone(440, 2.0)  # Ля первой октавы, 2 секунды
```

### Мелодия:
```python
notes = [262, 294, 330, 349]  # До-Ре-Ми-Фа
player.play_melody(notes, 0.5)  # По 0.5 сек каждая нота
```

### DTMF тоны:
```python
from advanced_sound_generator import AdvancedSoundGenerator

generator = AdvancedSoundGenerator()
generator.play_phone_number("123-456")  # Набор номера
```

## 🔧 Настройка для конкретных устройств

### Samsung:
- Обычно работает без проблем
- Рекомендуется использовать pygame

### Xiaomi:
- Может потребоваться дополнительные разрешения
- Попробуйте отключить оптимизацию батареи для Pydroid

### Huawei:
- Используйте только pygame-версии скриптов
- sounddevice может не работать
